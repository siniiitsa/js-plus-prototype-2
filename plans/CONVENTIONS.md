# Shared conventions

The conventions a **third** template leaned on, tested by a **fourth**. `plans/README.md` asked for this file "once a
second template shows which is which"; Lime showed it, and Grunge's layout-1 pass tested it:
every bullet below is one a Grunge session actually used (its running lists are *Conventions →
Inherited and used* in [`grunge/layout-1.md`](./grunge/layout-1.md),
[`grunge/layout-2.md`](./grunge/layout-2.md), [`grunge/layout-3.md`](./grunge/layout-3.md) and
[`grunge/layout-4.md`](./grunge/layout-4.md)), not one that merely reads as general. The
layout-2, layout-3 and layout-4 passes each added the rows they leaned on three times or more
that the file did not name, and their sections are listed after the layout-1 ones as *L2:*,
*L3:* and *L4:*. Editorial's layout-1 pass leaned on it a second time and has a column of its own
(its running list is *Inherited and used* in [`editorial/layout-1.md`](./editorial/layout-1.md));
the four rows it leaned on three times or more that the file did not name are added with a
Grunge cell of *not recorded*, *—* or the D group Grunge met them in. Its decorative language —
the dashed rule, the tape, the sparkle — stays in its plan, by this file's own rule below.
Editorial's layout-2 pass leaned on it a third time: a second Editorial column on A, B and C, an
Editorial column on D2 (its running list is *Inherited and used* in
[`editorial/layout-2.md`](./editorial/layout-2.md)), and the four rows it leaned on three times
or more that the file did not name — one in A, three in C — each with an Editorial layout-1 cell
of *—* where that pass never met it. Editorial's layout-3 pass leaned on it a fourth time: a third
Editorial column on A, B and C, an Editorial column on D3 (its running list is *Inherited and
used* in [`editorial/layout-3.md`](./editorial/layout-3.md)), and the four rows it leaned on three
times or more that the file did not name — one in A, one in B, two in C — the earlier Editorial
cells *—* where those passes never met them. Editorial's layout-4 pass, which closed its family,
leaned on it a fifth time: a fourth Editorial column on A, B and C, an Editorial column on D4 (its
running list is *Inherited and used* in [`editorial/layout-4.md`](./editorial/layout-4.md)), and
the one row it leaned on three times or more that the file did not name — *a Lime block paints its
ground from Scheme 1 keys*, in C, met five times — its layout-1 and layout-2 cells *not recorded*.
The dashed rule, leaned on five times as well, stays in the plans with the rest of Editorial's
decorative language. Pop's layout-1 pass leaned on it a sixth time, and is the first template
whose frames are not a variable mode outside the header: a *Pop (layout 1)* column on A, B, C
and D1 (its running list is *Inherited and used* in [`pop/layout-1.md`](./pop/layout-1.md)),
and the three rows it leaned on three times or more that the file did not name, all in A —
reading raw values where a variant binds nothing, reading a text style by name in the
template's own mode, and transcribing the frame's vectors — the earlier columns *not recorded*
or *—* where those passes never met them. Its stickers, scribbles, dot grids and 10px rules
stay in its plan, by this file's own rule below. Pop's layout-2 pass leaned on it a seventh time,
on a page bound to its mode again: a *Pop (layout 2)* column on A, B, C and D2 (its running list
is *Inherited and used* in [`pop/layout-2.md`](./pop/layout-2.md)), and the one row it leaned
on three times or more that the file did not name — *an empty slot whose well `s.muted` does
not read takes `Photo`'s `ink`*, in C, met by every Editorial pass and both of Pop's — the
Grunge and Editorial layout-1 cells *—*. Pop's layout-3 pass leaned on it an eighth time, on its
layout-2 page's bound mode over Lime's layout-3 tree: a *Pop (layout 3)* column on A, B, C and D3
(D3's first Pop column; its running list is *Inherited and used* in
[`pop/layout-3.md`](./pop/layout-3.md)), and the one row it leaned on three times or more that the
file did not name — *a card on another scheme is that scheme's binding, not always its ground*,
in C, written by Pop's layout-2 form session and met here by the audio card, the calendar card,
pricing's featured row and the form's card — the earlier columns *not recorded* or *—*.
Pop's layout-4 pass leaned on it a ninth time and closed the Pop family — and with it every
family — on its layout-3 page's bound mode over Lime's layout-4 tree: a *Pop (layout 4)* column on
A, B and C and a Pop column on D4 (its running list is *Inherited and used* in
[`pop/layout-4.md`](./pop/layout-4.md)), and the four rows it leaned on three times or more that
the file did not name — three in B (*probe a display string with a long word*, *scan a glyph
floor with the string drawn alone*, *a hand-off's trap is checked against the block before it is
coded*) and one in C (*a ring hides no anti-aliased photograph edge*), the earlier columns *not
recorded* or *—* where those passes never met them. Its sweep folded Pop's per-site pair
`(s.limeTree || s.pop)` into `s.limeTree`, which now names all four designed templates, so the
Pop columns' "the pair" is history: C's gate row says where it went. Its stickers beside the
artist's longer copy, which went behind it on three sections across two passes, stay in its plan
with the rest of Pop's decorative language.

This file **names and locates; it does not restate.** Each line is the bullet's own bold title,
the plan and heading it lives under, and the Grunge sections that leaned on it. Read the bullet
where it was written — its numbers and its reasons are there. Line numbers drift, so search the
title.

A new template's first plan says which group it inherits: **A** and **B** always; **C** if it
is another variant of a page already fitted (Editorial's layout-1 page is Lime's tree; Pop's
is Lime's tree in ten sections and Retro's media player in the eleventh, and its layout-2, -3
and -4 pages Lime's trees of those numbers in all ten); **D** only if its blocks are widened Lime blocks, as Grunge's, Editorial's and Pop's are —
D1 for Lime's layout-1 blocks, D2 for its layout-2 ones, D3 for its layout-3 ones, D4 for its
layout-4 ones.

## What is deliberately not here

- **A template's decorative language** — Retro's grain, torn edges, checkerboard and offset
  shadows; Lime's arcs and glows; Grunge's tears, lighten grain and seals; Editorial's dashed
  rule and tape; Pop's stickers, scribbles, dot grids and 10px rules. Each plan's
  *decorative language* section owns its own.
- **The `sectionVm` and live-seam rules.** They are CLAUDE.md's, and every plan reads that first.
- **The per-session procedure and the sweep list.** Lime layout 1's are the canonical ones; a new
  plan writes deltas against them, as Grunge's does.
