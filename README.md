# jp-plus-2

React application built with Vite. The React Compiler is enabled via
`babel-plugin-react-compiler` — see `vite.config.js`.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                        |
| ----------------- | ---------------------------------- |
| `npm run dev`     | Start the dev server with HMR      |
| `npm run build`   | Build for production into `dist/`  |
| `npm run preview` | Serve the production build locally |
| `npm run lint`    | Run ESLint over the project        |
